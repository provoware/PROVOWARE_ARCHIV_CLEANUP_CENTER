# PROVOWARE einfach starten

## Start

1. Projektordner entpacken.
2. `START_PROVOWARE.sh` doppelklicken.
3. Falls Kubuntu fragt, **Ausführen** wählen.
4. Das Programm öffnet die Oberfläche im Browser.

Alternativ im Terminal:

```bash
./START_PROVOWARE.sh
```

## Was passiert beim Start?

- Das Programm prüft kurz, ob wichtige Dateien vorhanden sind.
- Es sucht automatisch einen freien lokalen Anschluss.
- Läuft dieselbe Projektversion bereits, wird sie wieder geöffnet.
- Die Oberfläche ist nur auf diesem Computer erreichbar.

## Sicherheit

Dieser Entwicklungsstand **liest Dateien nur**. Er löscht, verschiebt oder überschreibt keine persönlichen Dateien.

Technische Angaben und Prüfberichte bleiben im Projektordner erhalten, sind für die normale Bedienung aber nicht nötig.
